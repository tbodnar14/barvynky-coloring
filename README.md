# Барвинки

Гра для малювання та розфарбовування українською. Працює як статичний сайт із збереженням малюнків у браузері та підтримкою offline після першого відкриття.

Доступні тваринки, динозаври, малюки, машинки, фрукти, планети, зима, Геловін, метелики.

Після завершення покрокового малюнка його можна відкрити з галереї для вільного редагування.
