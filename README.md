# Барвинки

Українська гра-розмальовка: п’ять тваринок, три динозаврики, п’ять малюків та вільне малювання.

Грати: https://tbodnar14.github.io/barvynky-coloring/

Версія: **0.7.0-rc1**, окремий локальний кандидат категорії «Малюки» для незалежної QA; публічний сайт поки працює на 0.5.2. Статичні й функціональні перевірки пройдено; додано анімацію частин тваринок і динозавриків та адаптивний стартовий екран. Спільне незалежне UX QA ще очікується. Точна відповідність текстур, порогів і кольорів нативному референсу та повне UX-приймання не підтверджені. iPad, Safari, Apple Pencil і встановлення на Home Screen ще потребують перевірки.

Малюнки зберігаються локально у браузері. Інший браузер або очищення його сховища змінює доступну галерею. Немає облікових записів, реклами чи аналітики. Експорт і частина категорій ще не реалізовані.

HTML, CSS, JavaScript ES modules та SVG без зовнішніх залежностей і компіляції. GitHub Pages публікує корінь гілки `main`; `.nojekyll` вимикає обробку Jekyll. Відносні шляхи й PWA manifest підтримують розміщення у підкаталозі. Service worker кешує файли для автономної роботи після першого завантаження.

Для локального перегляду запустіть статичний HTTP-сервер у каталозі репозиторію, наприклад `python3 -m http.server 8000 --bind 127.0.0.1`, і відкрийте `http://localhost:8000`.
